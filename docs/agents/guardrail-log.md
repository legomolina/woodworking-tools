# Guardrail log

Every rule, hook, check or agent instruction that exists to keep agents (and humans) on track, and the incident that justified it. Newest first.

Add an entry whenever you add, change or remove a guardrail, or when one catches something worth remembering. The `retro` skill is a good moment to review it. Each entry answers: what happened, why, and what now prevents it.
